# Hack Club Portfolio Website

A simple personal portfolio website built with HTML and CSS.

This repository is prepared for Hack Club submissions and includes a clean project structure, documentation, and license.

## Live Preview

Open the file below in your browser:

- `web/web.html`

## Project Structure

```text
web/
  index.html
  styles.css
```

## Tech Stack

- HTML5
- CSS3

## Getting Started

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `web/web.html` in your browser.

## Notes

- The page is fully static, no build tools required.
- Responsive styles are included for mobile and desktop.
